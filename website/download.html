Como instalar

Android

  1. Baixe o APK e abra o arquivo no aparelho.
  2. O Android vai pedir permissão para instalar de fora da loja — autorize apenas o Hero Play.
  3. Abra o app: ele mostra o ID (MAC) e a Chave do aparelho para você ativar.

Windows

  1. Baixe o instalador e execute.
  2. O Windows pode avisar que o autor é desconhecido — clique em "Mais informações" e depois em "Executar assim mesmo".
  3. O app abre mostrando o ID (MAC) e a Chave para ativação.
